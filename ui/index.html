      1 · Find a direction

      Give two sets of examples, one per line. Brainscan reads the residual stream for each, takes the difference of the set means at every layer, and scores how well that direction separates held-out examples. Directions are always measured on the original weights.

      Direction bank

        2 · Edit weights

        Where to remove it

        Embeddings plus attention and MLP outputs at all layers, strength 1, is the standard "abliteration" recipe (Arditi et al., 2024). Add a random-direction edit with the same settings as a control.

          3 · Compare original and edited

          Runs each prompt on the original and the edited weights (greedy, steering off) and checks side effects on neutral reference text.

          4 · Export the variant

          Saves the edited weights as a Hugging Face checkpoint, with brainscan_edits.json recording every edit and the base model. Paths are inside WSL; /mnt/h/... writes to the H: drive.

          Brainscan shows functional measurements: logit-lens probabilities and projections onto contrast vectors built from example texts. Each readout is labelled by how it was built. Nothing here measures experience.
